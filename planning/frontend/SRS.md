# SRS Frontend SIPERU

## Tujuan
Mendefinisikan kebutuhan fungsional dan non-fungsional untuk antarmuka pengguna SIPERU.

## Ruang Lingkup
Frontend menyediakan dashboard admin untuk peminjaman ruangan dan UI pengguna untuk melihat jadwal dan status booking.

## Kebutuhan Fungsional
- Dashboard statistik peminjaman dan ketersediaan ruangan.
- Daftar peminjaman dengan filter nama, ruangan, dan tanggal.
- Modal tambah, detail, ubah status, dan hapus peminjaman.
- Tampilan jadwal penggunaan per ruangan.

## Kebutuhan Non-Fungsional
- Responsif untuk mobile dan desktop.
- Aksesibilitas dasar.
- Loading state dan error state yang jelas.
- Konsistensi desain.

## Navigasi Utama
- Dashboard.
- Daftar Peminjaman.
- Jadwal Ruangan.

## Batasan
- Akses admin hanya untuk akun berizin.
- Upload mengikuti batas ukuran dan format.
