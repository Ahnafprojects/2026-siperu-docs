# SRS Infrastruktur SIPERU

## Tujuan
Mendefinisikan kebutuhan infrastruktur untuk menjalankan SIPERU secara stabil dan aman.

## Kebutuhan Fungsional
- Menjalankan backend ASP.NET dan frontend React + Vite lewat Docker Compose.
- Menyediakan port lokal untuk pengembangan.
- Persistensi database backend melalui volume.
- Dokumentasi operasional singkat untuk tim.

## Kebutuhan Non-Fungsional
- Setup lokal cepat dan konsisten.
- Mudah dijalankan oleh semua anggota tim.

## Batasan
- Repository infra mengasumsikan repo backend dan frontend berada di folder sibling.
